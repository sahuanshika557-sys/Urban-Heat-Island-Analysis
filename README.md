# Urban Heat Island Analysis and Heat Risk Prediction

## Overview

This project analyzes Urban Heat Island (UHI) effects in Lucknow, India using Landsat-8 satellite imagery, Google Earth Engine, and Machine Learning.

## Technologies Used

- Google Earth Engine
- Python
- Rasterio
- NumPy
- Pandas
- Scikit-Learn
- Matplotlib

## Features

- Land Surface Temperature (LST)
- NDVI Analysis
- NDBI Analysis
- Heat Risk Classification
- Hotspot Detection
- Random Forest Machine Learning

## Results

- Min Temperature: 22.72°C
- Max Temperature: 33.07°C
- Avg Temperature: 27.40°C
- Urban Heat Severity Score: 82.87
